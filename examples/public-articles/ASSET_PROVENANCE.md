# Original public asset fixtures

`public/tile.png`, `public/proof.woff2` and `public/site.css` are generated by
`tools/generate_asset_fixtures.py`. The two-colour tile and geometric font glyphs
were authored for this repository and are dedicated to the public domain under
CC0 1.0. They contain no copied system font, private material or external URL.

Reproduction uses test-only fonttools4.63.0 and brotli1.2.0; these are not runtime
or application-build dependencies. The font intentionally covers only A and
space; ordinary text uses native local fallback fonts. Timestamps are fixed for
deterministic output. The stylesheet references its declared digest.
